# 메인 화면 사진

`main.jpg` **파일 하나만 바꾸면** 메인 화면 오른쪽 큰 사진이 교체됩니다.

## 넣는 방법

1. 넣고 싶은 사진 파일 이름을 `main.jpg` 로 바꿉니다.
2. 이 폴더(`src/assets/hero/`)에 있는 기존 `main.jpg` 를 덮어씁니다.
3. 저장(커밋)하면 1~2분 뒤 사이트에 반영됩니다.

## 사진 고를 때

- **세로로 긴 사진**이 잘 맞습니다 (가로:세로 = 4:5 정도). 가로 사진을 넣으면 위아래가 잘립니다.
- 크기는 가로 1200px 이상이면 충분합니다. 더 커도 되고, 사이트가 알아서 줄여서 씁니다.
- 화면 **왼쪽에 짙은 색 유리를 덮은 효과**가 들어갑니다. 사진의 왼쪽에 중요한 것(얼굴, 글씨)이 있으면 가려지니, 오른쪽에 오도록 찍힌 사진이 좋습니다.
- 아이폰은 카메라 설정 > 포맷을 "가장 호환성 우선"으로 두면 `.jpg` 로 저장돼서 그대로 쓸 수 있습니다.

지금 들어있는 파일은 자리를 채워둔 임시 이미지입니다.
