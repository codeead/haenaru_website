# Design Brief: 해나루 종합설비 브랜드 & 홈페이지

> 작성: 2026-09-05 · 인터뷰 기반(사용자 응답 반영) · 이후 design-tokens / UI 키트 / 구현이 이 문서를 기준으로 진행된다.

## Problem

보일러가 멈추거나 물이 새면 집주인은 급하다. 급한 상태에서 검색하거나 소개받은 번호를 확인할 때, 대부분의 지역 설비업체는 확인할 수 있는 게 전화번호 하나뿐이다. "이 사람한테 우리 집을 맡겨도 되나"를 판단할 근거가 없어서, 결국 아는 사람 소개에만 의존하게 된다.

반대로 아버님(대표 김현욱) 입장에서는, 20년 가까이 쌓인 실제 시공 경험이 어디에도 남아 있지 않다. 명함 한 장 외에는 보여줄 게 없다.

## Solution

방문자가 10초 안에 "여기 진짜 일하는 사람이구나"를 느끼게 하는 사이트. 실제 시공 사진과 등록업체 정보, 대표 이름이 앞에 있고, 판단이 서면 바로 전화 버튼을 누를 수 있다. 아버님은 일이 끝날 때마다 사진 몇 장과 한 줄 설명을 올리기만 하면 되고, 그게 쌓여서 신뢰의 근거가 된다.

## Experience Principles

1. **근거가 수사보다 먼저** — "최고의 기술력" 같은 말 대신 실제 시공 사진, 등록업체 번호, 대표 이름을 보여준다. 지어낸 이야기(창업 스토리, 미확인 연차)는 쓰지 않는다.
2. **급한 사람 기준으로** — 방문자 상당수는 지금 물이 새는 중이다. 전화번호와 "무엇을 고치는지"가 어느 화면에서든 3초 안에 보여야 한다.
3. **눈이 편한 게 멋있는 것보다 중요** — 주 방문자에 어르신과 그 자녀 세대가 섞여 있다. 쨍한 색, 얇은 글씨, 어두운 배경으로 멋을 내지 않는다.

## Aesthetic Direction

- **Philosophy**: 노을 머금은 바다 (Sunset over calm sea). 상호 "해나루"(해 + 나루)에서 출발하되, 특정 사진이 아니라 고정 팔레트로 그 정서를 구현한다.
- **Tone**: 따뜻하고 동네스러움. 말 걸기 편한 이웃 가게. 정중하지만 딱딱하지 않게.
- **Reference points**: 동네 간판·인화 사진의 물성, 파스텔 톤의 차분한 생활 브랜드
- **Anti-references**:
  - 쨍하고 채도 높은 원색 위주 화면 (사용자가 명시적으로 거부)
  - 어두운 배경 + 작은 모노스페이스 = 눈 피로 (A안에서 확인된 문제)
  - 특정 배경 사진에서 색을 뽑아 만든 팔레트 (사진이 바뀌면 무너짐)
  - 지어낸 브랜드 서사 ("바닷가에서 나고 자란 30년" 류)
  - 어디에나 붙일 수 있는 파란색 SaaS 템플릿 느낌

## Brand Palette (확정)

사진이 아니라 **로고에서만** 유래하며, 로고 자체를 파스텔 톤으로 리컬러링해 사용한다.

| 토큰 | HEX | 역할 | 대비 |
|---|---|---|---|
| `--paper` | `#f9f8f5` | 기본 배경 | -- |
| `--surface` | `#ffffff` | 카드·패널 | -- |
| `--ink` | `#2c3338` | 본문 텍스트 | 12.07:1 (AAA) |
| `--ink-muted` | `#5d6b73` | 보조 텍스트 | 5.18:1 (AA) |
| `--sea` | `#3d7a94` | 주 버튼 배경 | 흰 글씨 4.76:1 (AA) |
| `--sea-deep` | `#2b5a70` | 링크·강조 텍스트 | 7.06:1 (AAA) |
| `--sea-soft` | `#d5e4ea` | 파스텔 면·태그 | 본문 9.84:1 |
| `--sea-pale` | `#eef5f7` | 아주 옅은 섹션 배경 | -- |

## Logo

- 기존 원색 로고(레드 `#f41b26` / 블루 `#0b51db`)를 파스텔 톤으로 리컬러링해 사용한다. (사용자 승인)
  - 해(원) `#f41b26` → `#e07a5f`
  - 삼각 구조 검정 → `#3f5560`
  - 파란 기둥 `#0851d9` → `#3d7a94`
  - 워드마크 `#0a51db` → `#2b5a70`
- 심볼 + 워드마크 + "종합설비" 조합을 기본 락업으로 사용. 좁은 화면에서는 심볼만.

## Typography

- **본문**: Pretendard (기존 유지) — 어르신 가독성 최우선, 400/500/700
- **제목**: **주아체 (Jua)** 확정. Google Fonts로 로드하며 Tailwind `font-display` 토큰에 연결.
- 숫자(전화번호·날짜)는 본문 서체 그대로, 크기를 충분히 키워서 사용. 작은 모노스페이스 캡션은 쓰지 않는다.

## Voice & Tone

말하듯이 친근하게. 명사 나열 대신 문장으로.

- ✅ "보일러가 고장 나면 언제든 전화 주세요"
- ✅ "당진 대덕동에서 배관·보일러·난방을 고칩니다"
- ❌ "보일러 시공 및 A/S 전문" (딱딱한 명사형)
- ❌ "최고의 기술력으로 고객 만족을 실현합니다" (근거 없는 수사)

## Existing Patterns

- Typography: Pretendard (jsdelivr CDN), Tailwind `font-sans` 매핑
- Colors: `src/styles/tokens.css`의 CSS 변수 + Tailwind `@theme inline` — 이번 팔레트로 전면 교체
- Spacing / radius: Tailwind 기본 스케일 + `--radius-*` 토큰 (둥근 모서리로 상향 조정 필요)
- Components: `Header`, `Footer`, `WorkCard`, `KakaoChannelButton`, `HeroCarousel`, `RepairHistory` — 구조는 유지하고 스타일만 교체
- Content: Astro Content Collections (`works`) + `site/config.json` 싱글턴, Decap CMS 연동

## Key Interactions

- 전화 버튼: 어느 페이지에서든 상단에 고정 노출. 탭하면 즉시 `tel:` 연결.
- 카카오 버튼: `kakaoChannelUrl`이 비어 있으면 자동으로 전화 버튼으로 대체 (기존 로직 유지).
- 수리 이력 카드: 탭하면 상세로 이동. 사진이 없거나 품질이 낮아도 레이아웃이 무너지지 않아야 함.
- 모바일 메뉴: 햄버거 탭 → 전체 메뉴 펼침. 애니메이션은 최소.

## Responsive Behavior

- 모바일 우선. 주 방문 경로가 검색 → 모바일이라고 가정한다.
- 640px 미만: 단일 컬럼, 내비는 햄버거, 히어로 높이 축소, 전화 버튼은 항상 보이게.
- 640px 이상: 수리 이력 2~3열, 내비 인라인 노출.

## Accessibility Requirements

- 본문 텍스트 대비 4.5:1 이상 (위 팔레트 표로 검증 완료)
- 본문 기본 크기 16px 이상, 어르신 고려해 행간 1.7 이상
- 모든 인터랙티브 요소에 보이는 포커스 표시
- 시공 사진에 CMS에서 입력한 설명(alt) 사용
- `prefers-reduced-motion` 존중 (기존 구현 유지)
- 라이트 모드 고정 검토 — 다크 모드에서 파스텔 팔레트가 흐려질 위험이 있어 별도 검증 필요

## Out of Scope

- 웹 문의 폼 / 이메일 발송 / 회원가입 (카카오 채널 + 전화로 통일)
- 온라인 견적 계산기, 예약 시스템
- 다국어
- 블로그 / 뉴스 섹션
- 사진 자동 보정 파이프라인 (아버님이 올린 원본을 그대로 사용, 빌드 시 리사이즈만)
