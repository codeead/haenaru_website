# 배포/CMS 설정 가이드 (최초 1회, 개발자용)

코드는 다 준비되어 있고, 아래는 GitHub·Netlify 웹 화면에서 클릭으로만 하는 설정입니다. 순서대로 진행하세요.

## 1. GitHub 레포 공개 설정

GitHub Pages 커스텀 도메인을 무료로 쓰려면 레포가 **Public**이어야 합니다.

- 레포 → Settings → General → 맨 아래 "Danger Zone" → 이미 Public이면 그대로 두면 됩니다.
- **주의**: `명함.jpeg`(계좌번호 포함)는 `.gitignore`에 등록되어 있어 커밋되지 않습니다. 혹시라도 과거 커밋 히스토리에 민감정보가 들어간 적이 있다면 알려주세요.

## 2. GitHub Pages 활성화

- 레포 → Settings → Pages → **Build and deployment → Source**를 **"GitHub Actions"**로 선택.
- `main` 브랜치에 push하면 `.github/workflows/deploy.yml`이 자동으로 빌드·배포합니다.

## 3. 커스텀 도메인 연결 (도메인 구매 후)

1. `astro.config.mjs`의 `site` 값과 `public/admin/config.yml`의 `site_url` 값을 실제 도메인(`https://내도메인.com`)으로 교체.
2. 레포 루트에 `public/CNAME` 파일을 만들고 도메인 한 줄만 적기 (예: `hanaru-setbi.com`).
3. GitHub → Settings → Pages → Custom domain에 같은 도메인 입력 후 저장.
4. 도메인 구입한 곳(가비아/후이즈 등) DNS 설정에서:
   - 최상위 도메인(`example.com`): A 레코드 4개를 GitHub Pages IP로 등록
     ```
     185.199.108.153
     185.199.109.153
     185.199.110.153
     185.199.111.153
     ```
   - `www` 서브도메인을 쓰려면: CNAME 레코드로 `사용자명.github.io` 등록
5. DNS 전파는 몇 분~몇 시간 걸릴 수 있습니다. GitHub Pages 설정 화면에서 인증서(HTTPS)가 자동 발급됩니다.

## 4. Netlify — CMS 로그인 전용 (실제 사이트 호스팅 아님)

1. https://app.netlify.com 에서 무료 계정으로 로그인 (GitHub 계정으로 로그인 가능).
2. **Add new site → Import an existing project → GitHub** → 이 레포 선택.
   - Build command / Publish directory는 아무 값이나 둬도 무방합니다. 이 Netlify 사이트는 실제로 방문자가 보는 사이트가 아니라, 로그인 중계 용도로만 씁니다. (그래도 자체적으로 한 번 빌드는 될 수 있는데, 무료 티어라 비용 문제 없습니다.)
3. 생성된 Netlify 사이트 → **Site configuration → Identity → Enable Identity**.
4. Identity → **Registration preferences**를 **"Invite only"**로 설정 (아무나 가입 못 하게).
5. Identity → **Services → Git Gateway → Enable Git Gateway**.
   - 이 단계에서 GitHub 로그인/권한 승인 창이 뜨면 승인합니다. (Netlify가 대신 커밋할 수 있도록 허용하는 것)
6. Identity → **Invite users** → 관리할 사람의 이메일(본인 + 아버님)을 입력해 초대 메일을 보냅니다.
7. 초대받은 사람은 메일의 링크를 눌러 비밀번호를 설정하면 로그인 준비 완료.

## 5. 확인

1. `https://내도메인.com/admin/` 접속.
2. Netlify Identity 로그인 창이 뜨는지 확인 → 로그인.
3. Decap CMS 화면(수리 이력 / 사이트 설정 메뉴)이 뜨면 완료.
4. 테스트로 수리 이력 하나를 등록 → 게시 → 1~2분 뒤 실제 사이트에 반영되는지 확인.

## 참고: 로컬에서 CMS 미리 테스트하기 (선택)

Netlify 연동 전에 로컬에서 먼저 CMS 저장 흐름만 확인하고 싶다면:

```bash
npx decap-server
# 새 터미널에서
npm run dev
```

그 다음 `public/admin/config.yml`의 `backend.name`을 임시로 `test-repo`(로컬 저장, 실제 커밋 안 함)나 `git-gateway`+`local_backend: true`로 바꿔 테스트할 수 있습니다. 테스트가 끝나면 반드시 원래 설정(`git-gateway`)으로 되돌려주세요.
