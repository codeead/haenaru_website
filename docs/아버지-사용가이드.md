# 홈페이지 관리 방법

인터넷 주소창에 아래 주소를 입력하고 들어가세요.

```
https://(사이트 주소)/admin/
```

처음 한 번은 메일로 받은 초대 링크를 눌러서 비밀번호를 만들어야 합니다. 그다음부터는 이메일과 비밀번호로 로그인하면 됩니다.

## 1. 수리 이력(시공 사례) 새로 올리기

1. 왼쪽 메뉴에서 **"수리 이력"**을 누릅니다.
2. 오른쪽 위 **"New 수리 이력"** 버튼을 누릅니다.
3. 아래 항목을 채웁니다.
   - **제목**: 예) 대덕동 단독주택 보일러 교체
   - **카테고리**: 목록에서 해당하는 것을 고릅니다.
   - **시공 날짜**: 작업한 날짜
   - **지역**: 동/읍 정도까지만 씁니다. 예) 당진시 대덕동
   - **대표 사진**: 클릭해서 사진을 한 장 올립니다. (가장 잘 나온 사진 한 장)
   - **추가 사진**: 필요하면 더 올릴 수 있습니다. 없으면 비워둬도 됩니다. 사진마다 "이 사진 설명" 칸에 한 줄 설명(예: "교체 전 배관 상태")을 적어주시면 더 좋습니다 — 안 적어도 사이트는 정상 작동합니다.
   - **설명**: 어떤 작업을 했는지 간단히 적으면 좋지만, 안 적어도 됩니다.
4. 오른쪽 위 **"저장(Save)"**을 누르고, 그다음 **"게시(Publish)"**를 누릅니다.
5. 1~2분 정도 지나면 실제 홈페이지에 반영됩니다.

> 사진은 아이폰 카메라 설정 > 카메라 > 형식에서 **"가장 호환됨(자동이 아니라 이 옵션)"**으로 바꿔두면 업로드가 항상 잘 됩니다.

## 2. 이미 올린 이력 수정/삭제하기

1. **"수리 이력"** 목록에서 수정할 항목을 클릭합니다.
2. 내용을 고친 뒤 저장 → 게시.
3. 삭제하려면 항목을 연 상태에서 오른쪽 위 메뉴(점 세 개 또는 "Delete entry")를 눌러 삭제합니다.
4. 아직 공개하고 싶지 않으면 맨 아래 **"임시저장(사이트에 아직 공개 안 함)"**을 켜두면 홈페이지에는 보이지 않고 관리 화면에만 남아 있습니다.

## 3. 전화번호·카카오톡 링크 등 기본 정보 수정하기

1. 왼쪽 메뉴에서 **"사이트 설정"** → **"기본 정보"**를 클릭합니다.
2. 전화번호, 영업시간, 카카오톡 채널 링크 등을 고칩니다.
3. 저장 → 게시.

카카오톡 채널 링크가 생기면 이 화면의 **"카카오톡 채널 링크"** 칸에 붙여넣기만 하면, 홈페이지의 모든 "카카오톡 문의" 버튼이 자동으로 그 링크로 연결됩니다.

## 궁금한 점이 생기면

화면이 이상하게 보이거나 저장이 안 되면 인터넷 연결을 확인하고 다시 시도해 보세요. 그래도 안 되면 캡처(화면 사진)해서 알려주세요.
