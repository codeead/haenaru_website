# 메인 화면 사진

이 폴더에 넣은 사진이 메인 화면에 뜹니다. **여러 장 넣으면 6초마다 서서히 바뀝니다.**

## 넣는 방법

- **한 장만 쓸 때**: 사진 이름을 `main.jpg` 로 바꿔서 기존 파일을 덮어씁니다.
- **여러 장 돌릴 때**: 이 폴더에 그냥 추가로 넣으면 됩니다. `main.jpg`, `main-2.jpg`, `main-3.jpg` 처럼 이름을 붙이면 그 순서대로 넘어갑니다.
- 확장자는 `.jpg` `.jpeg` `.png` `.webp` 를 씁니다.
- 저장(커밋)하면 1~2분 뒤 사이트에 반영됩니다.

## 사진 고를 때

- **비율은 신경 쓰지 않아도 됩니다.** 어떤 비율로 넣든 자리에 맞춰 자동으로 채워집니다(가운데 기준으로 남는 부분만 잘립니다). 다만 **세로로 긴 사진**(가로:세로 4:5 정도)이 가장 덜 잘립니다.
- 크기는 가로 1200px 이상이면 충분합니다. 더 커도 되고, 사이트가 알아서 여러 크기로 줄여서 씁니다.
- 사진 위에는 **왼쪽이 짙고 오른쪽으로 갈수록 옅어지는 유리막**이 덮입니다. 사진이 또렷하게 보이는 쪽은 오른쪽이니, 보여주고 싶은 것이 사진 오른쪽에 있으면 좋습니다.
- 아이폰은 카메라 설정 > 포맷을 "높은 호환성"으로 두면 `.jpg` 로 저장돼서 그대로 쓸 수 있습니다.

지금 들어있는 파일은 자리를 채워둔 임시 이미지입니다.
