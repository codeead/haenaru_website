# 시공사례 올리는 법

관리자 화면(CMS)은 쓰지 않는다. 시공사례는 **레포에 폴더를 하나 만들고 push**하면 올라간다.

## 1. 폴더 만들기

`src/content/works/` 아래에 `{연도}-{월}-{설명}` 형식으로 폴더를 만들고, 사진을 그 안에 같이 넣는다.

```
src/content/works/2026-09-대덕동-보일러교체/
├── index.md
├── cover.jpg      ← 대표 사진
└── after.jpg      ← 추가 사진 (없어도 됨)
```

폴더 이름이 그대로 주소가 된다 → `https://haenarueng.com/works/2026-09-대덕동-보일러교체/`

## 2. index.md 쓰기

```markdown
---
title: "대덕동 단독주택 보일러 교체"
category: "boiler"
workedAt: 2026-09-03
locationRegion: "당진시 대덕동"
coverImage: "./cover.jpg"
photos:
  - src: "./after.jpg"
    alt: "교체 후 보일러실"
draft: false
---

노후 보일러를 교체하고 배관 일부를 새로 잡았습니다.
```

| 항목 | 필수 | 설명 |
|---|---|---|
| `title` | ✅ | 목록 카드에 보이는 제목 |
| `category` | ✅ | 아래 표의 값 중 하나 (오타 나면 빌드 실패) |
| `workedAt` | ✅ | 시공 날짜. 이 값 기준 최신순 정렬 |
| `locationRegion` | ✅ | 동/읍 수준까지만. 지번은 쓰지 않는다 |
| `coverImage` | ✅ | 같은 폴더 기준 상대경로 (`./` 로 시작) |
| `photos` | | 추가 사진. `alt`는 화면읽기 프로그램용 한 줄 설명 |
| `draft` | | `true`면 사이트에 안 보임. 기본값 `false` |
| 본문 | | 비워도 된다 |

### `category`에 쓸 수 있는 값

`src/content/services.ts`의 `key`와 일치해야 한다.

| 값 | 표시되는 이름 |
|---|---|
| `boiler` | 보일러 시공 및 A/S |
| `heating` | 난방 배관공사 |
| `water-pipe` | 상하수도 배관공사 |
| `leak-detection` | 누수 탐지 |
| `thawing` | 해빙 |
| `remodeling` | 주택 리모델링 |
| `prefab` | 조립식 건축 |
| `coring` | 코어작업 |

## 3. 확인하고 올리기

```bash
npm run build     # 스키마 검증 — 오타/누락이 있으면 여기서 잡힌다
npm run dev       # 눈으로 확인 (http://localhost:4321/works)

git add src/content/works/2026-09-대덕동-보일러교체
git commit -m "시공사례: 대덕동 단독주택 보일러 교체"
git push
```

push하면 GitHub Actions가 자동으로 빌드·배포한다. **1~2분 뒤 사이트에 반영된다.**

## 사진에 대해

- 폰에서 받은 **원본 그대로 넣으면 된다.** Astro가 빌드할 때 자동으로 WebP 변환·리사이즈한다 (480KB 원본 → 30~140KB).
- 아이폰 사진은 HEIC라 처리가 안 된다. 아버님 폰에서 **설정 > 카메라 > 포맷 > "높은 호환성"**으로 바꿔두면 JPEG로 찍힌다. 이미 찍은 HEIC는 맥에서 미리보기로 열어 JPEG로 내보내면 된다.
- 개인 식별이 가능한 것(문패, 차량 번호판, 사람 얼굴)이 찍혔는지 한 번 보고 올린다.

## 전화번호·주소·카카오톡 링크 수정

`src/content/site/config.json` 한 파일만 고치면 헤더·푸터·문의 페이지에 전부 반영된다.

```json
{
  "phone": "041-358-5469",
  "mobile": "010-7183-5469",
  "kakaoChannelUrl": ""
}
```

`kakaoChannelUrl`이 빈 문자열이면 사이트의 카카오톡 버튼 자리에 **전화 문의 버튼이 대신** 표시된다. 카카오톡 채널을 만들면 채널 관리자센터 > 채팅 탭에서 채팅 링크를 복사해 여기에 넣는다.
